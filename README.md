## 🚀 Projetos práticos

### ☕ 1. CoffeeCart — Test Automation com Playwright

Projeto de automação de testes de interface desenvolvido com **Playwright e JavaScript**, utilizando o padrão **Page Object Model (POM)** para organizar e facilitar a manutenção dos testes.

**Principais cenários automatizados:**
- Adição e remoção de produtos do carrinho.
- Validação de preços e valores totais.
- Atualização de quantidades.
- Aplicação de promoções.
- Verificação da persistência do carrinho após atualizar a página.

**Tecnologias:** Playwright, JavaScript e POM.

📂 [Explorar projeto CoffeeCart](./playwright_coffecart_pom)

### 🐾 3. PetStore — Manual Testing & Test Case Design

Projeto de **Test Design e Test Execution** realizado na aplicação JPetStore, com elaboração de **16 Test Cases** envolvendo cenários positivos e negativos.

**Funcionalidades testadas:**
- Cadastro de usuários e validação de campos.
- Requisitos de senha e validação de email.
- Autenticação de usuários.
- Busca de produtos por categoria, nome e ID.
- Adição de produtos ao carrinho.

Os Test Cases foram documentados com **Steps, Expected Results, Priority e Execution Status**, disponibilizados em Excel e PDF.

**Competências:** Manual Testing, Test Design, Functional Testing e Test Execution.

📂 [Explorar Test Cases do PetStore](./manual_testing/test_cases)

---

### 🍬 4. Sweet Shop — Exploratory Testing & Bug Reporting

Projeto de testes exploratórios realizado na aplicação Sweet Shop, com foco na investigação de problemas funcionais e de usabilidade.

Foram documentados **4 relatórios de problemas e oportunidades de melhoria**, incluindo evidências em vídeo.

**Principais descobertas:**
- Oportunidade de melhoria na seleção de quantidades do carrinho.
- Possível problema relacionado à ausência de limite de produtos.
- Falha que impede a conclusão do checkout.
- Ausência de mensagem de erro durante uma falha no checkout.

Cada relatório apresenta **Steps to Reproduce, Expected Result, Actual Result, Severity e evidências**, permitindo compreender e reproduzir os comportamentos identificados.

**Competências:** Exploratory Testing, Usability Testing, Bug Reporting, Defect Reproduction e Severity Assessment.

📂 [Explorar Bug Reports do Sweet Shop](./manual_testing/bug_reports)
