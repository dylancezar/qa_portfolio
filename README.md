Projeto de automação de testes de interface utilizando **Playwright e JavaScript**, organizado com o padrão **Page Object Model (POM)**.

- Adição e remoção de produtos do carrinho.
- Validação de preços e valores totais.
- Atualização de quantidades.
- Validação de promoções.
- Verificação do comportamento do carrinho após atualizar a página.
