# PetStore | Manual Test Cases

## Overview

This project contains **16 manual test cases** designed and executed for the [JPetStore](https://jpetstore.mate.academy/actions/Catalog.action) web application.

The goal is to demonstrate practical skills in **Test Design, Test Case Creation, and Test Execution**, covering positive and negative testing scenarios across different application functionalities.

## Test Coverage

The test cases cover:

- **User Registration:** User ID validation, password requirements, email validation, and required fields.
- **Authentication:** Login functionality and required field validation.
- **Product Search:** Searching products by category, name, and product ID.
- **Shopping Cart:** Adding products from the product details page and product list.
