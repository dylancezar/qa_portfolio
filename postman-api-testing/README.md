# 🚀 API Testing com Postman

## 📌 Sobre o projeto

Projeto prático de **API Testing** desenvolvido com Postman, utilizando requisições HTTP e scripts de validação em JavaScript.

O objetivo é validar o comportamento de endpoints, verificar respostas da API e identificar possíveis falhas.

## 🛠️ Tecnologias utilizadas

- Postman
- JavaScript
- REST API
- JSON
- HTTP Methods
- Assertions com `pm.test()`

## 🧪 Testes realizados

A Collection contém requisições e testes automatizados para validação de respostas da API.

Entre as verificações estão:

- Validação de status codes HTTP.
- Verificação de respostas das requisições.
- Testes de endpoints relacionados ao cadastro de usuários.
- Organização de requisições e testes em uma Collection.

## 📥 Como importar o projeto no Postman

**1. Baixe a Collection**

Acesse esta pasta no GitHub e baixe o arquivo `.postman_collection.json`.

**2. Abra o Postman**

Acesse [Postman](https://www.postman.com/) pelo navegador ou aplicativo desktop.

**3. Importe a Collection**

- Clique em **Import**.
- Selecione **Files**.
- Escolha o arquivo `.postman_collection.json` baixado.
- Confirme a importação.

**4. Acesse os testes**

A Collection aparecerá na seção **Collections**, mantendo a organização das pastas, requisições e scripts.

**5. Configure e execute**

- Verifique a URL da API utilizada.
- Configure as variáveis de ambiente necessárias, caso existam.
- Abra uma requisição e clique em **Send**.
- Confira os resultados das validações na seção **Test Results**.

> **Observação:** a execução depende de a API estar acessível e de eventuais credenciais ou variáveis estarem configuradas corretamente.

## 🎯 Objetivo

Demonstrar conhecimentos práticos em **API Testing**, validação de respostas HTTP, criação de scripts de teste com JavaScript e organização de testes utilizando Postman.
